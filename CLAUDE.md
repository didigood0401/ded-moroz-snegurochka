# Проект РЕНА: новогодний сайт заказа Деда Мороза и Снегурочки

Демо-сайт без сервера: чистый HTML/CSS/JS, три файла `index.html`, `style.css`, `app.js`. Оплата и телефоны — заглушки.

- Репозиторий: https://github.com/didigood0401/ded-moroz-snegurochka (ветка `main`)
- Сайт (GitHub Pages): https://didigood0401.github.io/ded-moroz-snegurochka/
- Деплой: `git push` в `main`, Pages обновляется сама за 1–2 минуты.

## Устройство
- `index.html`: каркас, SVG-`<defs>` с градиентами (источник «объёма» иллюстраций), гирлянда.
- `style.css`: две темы (`card`, `night`) через `data-theme`; блок «ПРЕМИУМ-ОФОРМЛЕНИЕ» в конце: гирлянда, ёлки, анимации героев.
- `hero3d.js`: 3D-сцена (three.js с CDN через importmap в `index.html`): Дед Мороз, Снегурочка, ёлки, шишки, снег. Подключается из `app.js` функцией `mount3D`. 3D работает только по http(s), с `file://` покажется SVG.
- `app.js`: данные программ и цены, SVG-иллюстрации (`santa`, `maiden`, `art`, `branch`, `cone`, `firDeco`), роутер по `#/`, корзина в `localStorage`, снег.

## Окружение
- Команды выполняются на компьютере пользователя (Windows, PowerShell) через `mcp__local__run`. Там нет `node`.
- Файлы, записанные инструментом Write/Edit, на компьютер пользователя автоматически не попадают. Проверять `Get-Content` и при необходимости записывать файл командой.
- `gh` уже авторизован под `didigood0401`.
